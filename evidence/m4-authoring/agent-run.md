# AI 에이전트 시안 작성 실측 (M4 4-E)

- 방법: 별도 Claude Code 세션(`claude -p`, headless)을 로컬 Docker MCP(`/mcp`)에만 연결(`--strict-mcp-config`, 허용 도구 `mcp__dsites__*`, 스크립트 토큰). 입력은 가상의 업체 리드 요약(테니스 레슨, 블로그 글 8개 요약, 사진 없음). 게시는 금지.
- M2 실측(evidence/m2-mcp/agent-run.md)과 같은 방식이다. 이번에는 고객 등록·지침 읽기·AI 이미지·시안 링크까지 한 번에 했다.

## 관찰

- 서버 안내대로 지침을 먼저 읽고, 같은 전화번호 고객이 없는지 확인한 뒤 등록했다.
- 사진이 없자 작성 규칙에 따라 실제 작업물이 아닌 일러스트로 첫 화면 이미지를 만들고, 그 이유를 보고했다.
- 자료에 없는 수치(경력 연수, 가격)를 만들지 않고 확인 항목으로 넘겼다(코치 경력, 가격 공개 여부, 수업 시간, 주소, 후기 게재 동의 등).
- 시안 링크가 `localhost`라는 점을 스스로 지적했다(로컬 환경이라 정상).
