발견한 문제와 처리(커밋 "fix: authoring findings")

| 심각도 | 문제 | 처리 |
| --- | --- | --- |
| 불편 | AI 도구 연결 방법 없음, "MCP" 용어 | 사이트 목록 안내에 "AI 도구 연결 방법" 화면 링크(Claude·ChatGPT 단계, 연결 주소) |
| 불편 | 고객 등록 주체가 화면마다 다름 | 안내를 "AI 도구 또는 고객 메뉴"로 통일 |
| 불편 | 작업 기록의 AI 작업이 "스크립트 · AI 이미지 만듦"뿐 | AI 도구 기록에 용도·대상 사진 등 세부 표시. 실제 운영에서는 Authentik 로그인한 운영자 이름이 남음(시연 데이터만 스크립트) |
| 불편 | 지운 사진이 기록에 무엇인지 없음 | 사진 키 일부 표시 |
| 불편 | 사진이 쓰이는지 카드에서 안 보임 | "미사용" 표시 추가 |
| 사소 | AI 비용이 사진을 지우면 줄어듦 | "남아 있는 AI 사진 기준"으로 표기 |

| 사소 | 고객 요청의 시각·기록자 없음 | 기록한 사람 표시(요청 일시는 AI가 받은 그대로) |
| 사소 | 지침 화면 안내의 기술 용어와 예시 섹션명 | 운영자 말로, 실제 섹션 이름 예시 |
| 사소 | 스크립트가 만든 버전이 "운영자 · 스크립트" | "스크립트"로 표시 |
