# 운영자 하루 업무 사용성 — 기준선 (프로덕트 오너 에이전트, 화면만 사용)

모든 과제 성공, 평균 4.4. 스크린샷: `po-baseline/`.

| 과제 | 결과 | 클릭 | 점수 | 이유 |
|---|---|---|---|---|
| T1 오늘 할 일 파악 | 성공 | 약 4 | 4 | 결제 메뉴 배지(3)와 "확인 필요" 탭이 급한 순으로 정리돼 좋음. 시안 전달·운영자 정지 사이트는 할 일 목록에 없어 사이트 목록을 직접 훑어야 함 |
| T2 노원 피아노 입금 처리 | 성공 | 약 5 | 4 | 입금 창에 금액·기간이 미리 채워져 있고 설명 친절. 공개 상태는 사이트 화면으로 이동해야 확인. 머리말 주소 링크는 오류 탭으로 열림 |
| T3 반짝 이사청소 시안 링크 재전송 | 성공 | 약 4 | 4 | "링크 복사", "안내문 복사" 버튼은 바로 보이지만 안내문 내용을 복사 전에 볼 수 없음. 사이트에 고객 연결이 없어 누구에게 보낼지 화면에서 알 수 없음. 모바일 시안은 잘 열림 |
| T4 첫 화면 제목 변경 | 성공 | 약 4 | 5 | 편집 탭 "첫 화면 큰 제목" 칸 → 초안 저장(v2) → 같은 시안 링크에 즉시 반영 |
| T5 도봉 풋볼 도메인 연결 | 성공 | 3 | 5 | 입력 후 "연결" → 즉시 "검증 대기", CNAME 값과 "사장님께 보낼 안내문 복사" 버튼. 안내문 본문은 확인 못 함 |
| T6 깔끔 사무실 청소가 안 보이는 이유 | 성공 | 2 | 5 | 결제 목록·사이트 개요 모두 "20일 연체로 공개 중단, 입금하면 바로 다시 공개" |
| T7 AI 도구로 만드는 법 찾기 | 성공 | 약 3 | 4 | 처음에 상단 "지침"으로 갔는데 AI가 읽는 문서였음. 실제 안내는 사이트 목록 문단 안의 작은 링크 "AI 도구 연결 방법" |
| T8 이번 달 입금 합계와 김철수 고객 | 성공 | 약 4 | 4 | 결제 내역에서 "이번 달"을 누르면 합계가 나옴. 기본이 "최근 3개월". 김철수 고객 상세에 반짝 이사청소가 빠져 헷갈림 |

## 발견한 문제

| 심각도 | 위치 | 문제 | 기대한 동작 |
|---|---|---|---|
| 불편 | 결제 › 확인 필요, 전체 | 입금까지 끝난 상쾌공간 입주청소가 운영자 정지로 내려가 있는데 어떤 할 일 목록에도 없음. 정지 사유도 개요에서 확인 못 함 | 오늘 할 일에 표시, 정지 사유·정지한 사람 표시 |
| 불편 | 전체 | 시안을 보내거나 후속 연락할 사이트를 모아 보는 화면이 없음 | 입금·연체·시안 후속을 한 화면에 모은 "오늘 할 일" |
| 불편 | 사이트 개요 › 고객(사장님) | 노원 피아노, 깔끔, 반짝 사이트에 고객 미연결. 반짝은 대표자·전화가 김철수와 같은데 김철수 상세에는 2곳만 | 미연결 경고, 같은 연락처면 연결 제안 |
| 불편 | 상단 메뉴 | "AI 도구 연결 방법"이 메뉴에 없고 "지침"은 AI용 문서 | 상단 메뉴에 "AI로 만들기" |
| 불편 | 사이트 머리말 주소 링크 | https 공개 주소가 새 탭에서 접속 오류(로컬 환경 영향일 수 있음) | 실제로 열리는 공개 주소 |
| 사소 | 시안 링크 / 도메인 안내문 복사 | 복사 전에 안내문 내용을 볼 수 없음 | 미리보기·펼쳐 보기 |
| 사소 | 노원 피아노 공개 사이트 | 상호는 피아노인데 본문은 축구 레슨(시드 데이터) | 확인 못 함 |
| 사소 | 첫 화면(세션 만료 시) | 빈 표와 "로그인이 만료" 알림만, 로그인 화면으로 보내지 않음 | 자동으로 로그인 화면 |
| 사소 | 결제 내역 | 기본 기간 "최근 3개월" | 기본값 "이번 달" |

## 가장 먼저 고칠 3가지
1. 입금·연체·시안 후속·운영자 정지를 한 화면에 모은 "오늘 할 일".
2. 고객 미연결 사이트 경고와 연결 유도.
3. AI 제작 안내를 상단 메뉴로, 운영자 정지 사유를 사이트 개요에.

## 처리 메모 (개발)
- 1~3, 안내문 미리보기, 결제 내역 기본 기간: 1회차에서 반영.
- 머리말 https 주소: 로컬은 http 라우터라 열리지 않는 것이 정상(스테이징·운영은 https). 평가에서 제외하도록 다음 회차 안내에 적음.
- 세션 만료: `api.ts`는 401에서 두 번 재시도 후 로그인으로 보낸다. 로컬 목업 인증 서버 재시작 등으로 갱신이 거부된 순간을 본 것으로 보이며, 재현되면 다시 본다.
- 시드 본문: 레슨 템플릿 예시를 재사용한 시연 데이터. 평가에서 제외.
