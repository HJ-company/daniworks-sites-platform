# 운영자 하루 업무 사용성 — 1회차 (프로덕트 오너 에이전트, 화면만 사용)

모든 과제 성공, 평균 4.75 (기준선 4.4). 스크린샷: `po-round1/`.

| T2 노원 피아노 입금 처리 | 성공 | 4+2 | 4 (4) | 처리는 쉬움. 알림이 "입금을 확인했습니다"뿐이라 공개 상태·납부 기간은 사이트 화면에서 따로 확인 |

## 발견한 문제

| 심각도 | 위치 | 문제 | 기대한 동작 |
|---|---|---|---|
| 불편 | 고객 상세(김철수), 사이트 개요 | 반짝·깔끔 사이트가 "같은 연락처의 고객: 김철수"로 제안되는데 고객 화면엔 2곳만 | 고객 화면에 같은 연락처의 미연결 사이트, 바로 연결 |
| 불편 | 첫 화면 운영자 정지, 고객 상세 | 상쾌공간 입주청소가 "사유 없음"으로 정지됨 | 정지 사유 필수 |
| 불편 | 입금 확인 알림 | 공개 상태·납부 기간 없음 | "노원 피아노 교습소 · 12/15까지" 같은 결과 |
| 불편 | 구독 카드, 입금 확인 창 | "30,000원(부가세 별도)"인데 입금 기본값 30,000원. 30,000원과 33,000원 중 무엇을 받아야 하는지 모호 | 실제 입금 금액 명시 |
| 불편 | 연체·중단 사이트 | 사장님께 보낼 입금 요청 안내문(금액·계좌·기한)이 없음. 계좌번호도 화면에 없음 | "입금 요청 안내문 복사" |
| 사소 | 편집 탭 | "초안"과 "시안" 용어가 섞임. 저장 알림에 시안 링크 반영 안내 없음 | 저장 알림에 반영 여부 |
| 사소 | 결제 내역 | 고객 미연결 사이트는 고객 칸이 "-" | 미연결 표시와 연결 링크 |

## 처리 메모 (개발)
- 2회차 반영: 고객 화면의 같은 연락처 미연결 사이트와 연결 버튼, 콘솔 정지 사유 필수, 입금 확인 알림에 상호·납부 기간·재공개, 입금 요청 안내문(금액·이용 기간·계좌·다음 일. 계좌는 콘솔 설정 `BILLING_ACCOUNT`), 저장 알림에 "사장님 시안 링크에도 바로 반영".
- 부가세: 받을 금액을 공급가로 할지 부가세 포함으로 할지는 PRD 미결 사항("요금제 세부 … 부가세 표기")이다. 이번에 정하지 않고 표기는 "(부가세 별도)"로 둔다.
- 결제 내역 고객 칸: 고객 연결 동선(사이트·고객 화면, 오늘 할 일)을 늘렸으므로 따로 두지 않음.
- "초안"(저장된 버전)과 "시안"(사장님 링크)은 다른 대상이라 용어는 유지하고 저장 알림으로 연결 관계를 알림.
