# 단순화 점검 (M4 마무리)

## 찾는 방법

서로 독립된 두 리뷰가 같은 코드를 따로 봤다. 둘 다 읽기만 했고, 동작을 바꾸지 않는 단순화만 찾게 했다.
- **codex:** `codex exec -s read-only`. 후보 14개.
- **코드를 처음 보는 Claude 에이전트:** 기존 판단을 넘기지 않고 코드만 줬다. 후보 22개와 "보고도 고치지 않을 것" 목록.

## 반영한 것 (커밋 3개)

1. **안 쓰는 코드** (`730e1fe`):
   - **렌더러:** M1 호출용 `toSitePages`·`toPageData`, `validateSiteConfig`, 넘겨지지 않는 `hydrate` 옵션, `RenderResult.ms`, 쓰지 않는 barrel export.
   - **API:** 로그인 뒤 읽히지 않는 `Actor.groups`, 재수출, import.
   - **콘솔 Worker:** 토큰 요청에 넘기기만 하던 `env` 매개변수.
   - **라우터:** `page()`의 headers 옵션.
   - **콘솔:** `MetricsReport` 타입.
   - **주석:** 예전 동작을 설명하던 주석을 고쳤다.
2. **API 중복** (`b3638f9`):
   - 시안 링크와 내부 미리보기의 렌더를 함수 하나로 합쳤다.
   - 공용 에셋 확인을 `sharedCss` 하나로 합쳤다(HEAD 요청 제거).
   - 반복되던 식을 이름 있는 함수로 바꿨다. `purgeAfter`, `cycleEnd`, `registrarHost`, `sameOwner`, `escapeHtml`.
   - 마지막 정지 기록 조회 SQL을 한 곳에 뒀다.
   - 재게시 목록에서 사이트를 다시 조회하던 쿼리를 없앴다.
3. **콘솔 중복** (이 커밋):
   - 안내문 복사·보기 블록 세 벌(시안, 입금 요청, 도메인)을 `CopyableMessage` 하나로 합쳤다. 클립보드 복사와 알림은 `useCopy`로 모았다.
   - KST 오늘 날짜 계산은 `kstToday`로 모았다.

## 고치지 않은 것과 이유

- **M1 KV 호스트 레코드 호환(문자열 레코드, `site:<id>` 포인터), v1 설정 지원, `render_id` 없는 R2 경로:** 저장된 실제 데이터가 이 경로를 탈 수 있다. 지우면 데이터 이전이나 제품 결정이 필요하다.
- **api와 router의 `keys.ts` 공유, 지표 정의 공유:** Worker가 서로 다르다. 공유 패키지를 두는 비용이 줄이는 줄보다 크다.
- **결제 상태 계산의 coverage 이중 계산:** 위험이 중간인데 얻는 성능 이득은 무시할 만하다.
- **콘솔 mutation의 `onSuccess` 세 줄 반복:** 과설계가 아니라 짧은 반복이다. 10개 파일을 건드리는 만큼의 가치가 없다.
- **스키마 패키지의 추론 타입(`ServiceContent`, `InquirySubmission`):** 패키지 공개 표면이라 남겼다.
- **동시성 보호(리스, `billing_rev`, 자산 tombstone), 비용 큰 호출 앞의 이른 검사:** 필요한 장치다.
