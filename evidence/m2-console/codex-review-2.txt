## Anti-Patterns to Flag

| Anti-pattern | Consequence and preferred pattern |
|-------------|-----------------------------------|
| `await response.text()` or similar buffering on unbounded data | Can exhaust Worker memory; [stream large or unbounded bodies](references/runtime-patterns.md#stream-request-and-response-bodies). |
| Hardcoded secrets in source or config | Leaks credentials through version control; use Wrangler secrets. |
| `Math.random()` for security-sensitive tokens or IDs | Predictable values; use `crypto.randomUUID()` or `crypto.getRandomValues()`. |
| Async work started without awaiting, returning, or attaching it to `ctx.waitUntil()` | Work can be dropped and errors missed; tie it to the request or background-work lifetime. |
| Module-level mutable request state | Leaks data across requests and can cause I/O ownership errors; pass request state explicitly. |
| Cloudflare REST API calls for operations available through Worker bindings | Adds network and authentication overhead; use the available binding. |
| `ctx.passThroughOnException()` used as general error handling | Can conceal Worker failures by forwarding to the origin; use explicit error handling and structured error responses. |
| Hand-written `Env` that duplicates Wrangler bindings | Can drift from configuration; generate binding types with `wrangler types`. |
| Direct string comparison of secret values | Can expose timing differences; use the [Web Crypto comparison pattern](references/runtime-patterns.md#use-web-crypto-for-secure-token-generation). |
| Destructuring `ctx` methods, such as `const { waitUntil } = ctx` | Loses the receiver; call `ctx.waitUntil(...)`. |
| `any` on `Env` or handler parameters | Hides binding and handler contract errors; use the project's generated and platform types. |
| `as unknown as T` to force a platform type match | Hides incompatibilities; fix the underlying contract. |
| `implements` used in place of extending a platform base class | Does not inherit runtime behavior, `this.ctx`, or `this.env`; use the appropriate base class. |
| Unbound `env.X` in a platform class method | Bindings are available through `this.env.X`; see [binding access patterns](references/platform-apis.md#binding-access--the-most-common-error). |
| Applying one serialization rule across Queues, Workflow steps, storage, and WebSockets | Can reject valid payloads or accept unsupported ones; check the [specific API and encoding](references/platform-apis.md#serialization-boundaries). |

 * Operators reach the console through Cloudflare Access. This re-verifies Access's JWT so the
 * Worker is safe even if a route bypasses Access; without Access config it refuses to serve.

async function authorized(request: Request, env: Env): Promise<boolean> {
  if (env.ACCESS_TEAM_DOMAIN && env.ACCESS_AUD) {
    const token = request.headers.get("cf-access-jwt-assertion");
    if (!token) return false;
    jwks ??= createRemoteJWKSet(new URL(`https://${env.ACCESS_TEAM_DOMAIN}/cdn-cgi/access/certs`));

    } catch {

    }
  }

}

export async function api<T>(path: string, init: RequestInit & { json?: unknown } = {}): Promise<T> {
  const { json, ...rest } = init;
  const res = await fetch(`/api${path}`, {
    ...rest,
    headers: { ...(json !== undefined ? { "content-type": "application/json" } : {}), ...rest.headers },
    body: json !== undefined ? JSON.stringify(json) : rest.body,
  });
  const text = await res.text();
  const data = text ? (JSON.parse(text) as unknown) : null;
  if (!res.ok) {
    const body = data as { error?: string; details?: unknown } | null;
    throw new ApiError(res.status, body?.error ?? `HTTP ${res.status}`, body?.details);
  }
  return data as T;
}

/** Validation details from the api, one per line, under the message. */
export function ErrorAlert({ error }: { error: unknown }) {
  if (!error) return null;
  const details = error instanceof ApiError && Array.isArray(error.details) ? (error.details as string[]) : [];
  return (
    <Alert severity="error" sx={{ whiteSpace: "pre-line" }} data-testid="error-alert">
      {error instanceof Error ? error.message : String(error)}
      {details.length ? `\n${details.join("\n")}` : ""}
    </Alert>
  );
}

export function StatusChip({ status, cancelled }: { status: string; cancelled?: string | null }) {
  if (cancelled) return <Chip size="small" label="해지" color="default" />;
  const map: Record<string, { label: string; color: "success" | "warning" | "default" | "error" | "info" }> = {
    active: { label: "운영", color: "success" },
    suspended: { label: "정지", color: "warning" },
    pending: { label: "검증 대기", color: "info" },
    failed: { label: "실패", color: "error" },
    removing: { label: "삭제 중", color: "default" },
  };
  const entry = map[status] ?? { label: status, color: "default" as const };
  return <Chip size="small" label={entry.label} color={entry.color} />;
}

const ToastContext = createContext<(message: string) => void>(() => undefined);

export function ToastProvider({ children }: { children: ReactNode }) {
  const [message, setMessage] = useState<string | null>(null);
  const show = useCallback((text: string) => setMessage(text), []);
  return (
    <ToastContext.Provider value={show}>
      {children}
      <Snackbar open={Boolean(message)} autoHideDuration={3000} onClose={() => setMessage(null)} message={message ?? ""} />
    </ToastContext.Provider>
  );
}

export interface AssetResult {
  /** Use this in config photos: `{ key, alt, width, height }`. */
  key: string;
  width: number;
  height: number;
  bytes: number;
  url: string;
}

/** Reads a body stream, aborting with 413 as soon as it passes the limit (no Content-Length trust). */
export async function readLimited(stream: ReadableStream<Uint8Array> | null, limit = MAX_INPUT_BYTES): Promise<Uint8Array> {
  if (!stream) return new Uint8Array();
  const reader = stream.getReader();
  const chunks: Uint8Array[] = [];
  let total = 0;
  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    total += value.byteLength;
    if (total > limit) {
      await reader.cancel();
      throw new HttpError(413, "사진이 너무 큽니다");
    }
    chunks.push(value);
  }
  const out = new Uint8Array(total);
  let offset = 0;
  for (const chunk of chunks) {
    out.set(chunk, offset);
    offset += chunk.byteLength;
  }
  return out;
}

/** Reads the upload body: raw image bytes, or JSON `{ url }` to fetch an https image (MCP, blogs). */
async function readUpload(request: Request): Promise<{ bytes: Uint8Array; name: string | null }> {
  const type = request.headers.get("content-type") ?? "";
  if (type.startsWith("application/json")) {
    // Only a URL is expected; read at most 4 KB before parsing.
    const raw = await readLimited(request.body, 4096);
    let body: { url?: string } | null = null;
    try {
      body = JSON.parse(new TextDecoder().decode(raw)) as { url?: string };
    } catch {
      throw new HttpError(400, "요청 본문이 JSON이 아닙니다");
    }
    const url = body?.url;
    if (!url || !/^https:\/\/[^\s]+$/.test(url)) throw new HttpError(400, "url은 https:// 주소여야 합니다");
    // No Referer: Naver blog images refuse foreign referrers but serve requests without one.
    const res = await fetch(normalizeNaverImage(url), { redirect: "follow", headers: { accept: "image/*" } });
    if (!res.ok) throw new HttpError(422, `사진을 가져오지 못했습니다 (${res.status})`);
    return { bytes: await readLimited(res.body), name: url };
  }
  return { bytes: await readLimited(request.body), name: request.headers.get("x-file-name") };
}

/**
 * Stores an uploaded photo for a site: normalized JPEG plus WebP variants in R2, a row in
 * `assets`. Content-addressed by the input bytes, so the same upload returns the same key.
 */
export async function uploadAsset(env: Env, site: SiteRow, request: Request): Promise<AssetResult> {
  const { bytes, name } = await readUpload(request);
  const hash = await sha256Hex(bytes);
  const file = `${hash}.jpg`;
  const key = `m:${site.id}/${file}`;
  const url = `/_media/${site.id}/${file}`;

  const existing = await env.DB.prepare("SELECT width, height, bytes FROM assets WHERE key = ?")
    .bind(key)
    .first<{ width: number; height: number; bytes: number }>();
  if (existing) return { key, url, ...existing };

  const photo = await processPhotoExclusive(bytes);
  const meta = { httpMetadata: { contentType: "image/jpeg", cacheControl: "public, max-age=31536000, immutable" } };
  await env.SITES.put(r2MediaKey(site.id, file), photo.main, meta);
  for (const variant of photo.variants) {
    await env.SITES.put(r2MediaKey(site.id, variantUrl(file, variant.width)), variant.bytes, {
      httpMetadata: { contentType: "image/webp", cacheControl: "public, max-age=31536000, immutable" },
    });
  }
  await env.DB.prepare(
    "INSERT OR IGNORE INTO assets (key, site_id, r2_key, mime, width, height, bytes, original_name, created_at) VALUES (?, ?, ?, 'image/jpeg', ?, ?, ?, ?, ?)",
  )
    .bind(key, site.id, r2MediaKey(site.id, file), photo.width, photo.height, photo.main.byteLength, name, new Date().toISOString())
    .run();
  return { key, url, width: photo.width, height: photo.height, bytes: photo.main.byteLength };
}

/**
 * Handles a visitor inquiry routed from the public router (via RPC, never from the internet):
 * validation, spam checks (honeypot, timing, Turnstile, rate limits), storage, then mail.
 */
export async function submitInquiry(
  env: Env,
  request: InquiryRequest,
  waitUntil: (promise: Promise<unknown>) => void,
): Promise<InquiryResponse> {
  const parsed = inquirySubmissionSchema.safeParse(request.body);
  if (!parsed.success) {
    return { status: 422, body: { ok: false, error: "입력 내용을 확인해 주세요", details: formatIssues(parsed.error) } };
  }
  const input = parsed.data;
  // Bots: answer like a success so they learn nothing, store nothing.
  if (input.website || (input.elapsedMs !== undefined && input.elapsedMs < LIMITS.minElapsedMs)) {
    return { status: 200, body: { ok: true } };
  }

  const site = await env.DB.prepare("SELECT id, status, cancelled_at, notify_email FROM sites WHERE id = ?")
    .bind(request.siteId)
    .first<{ id: string; status: string; cancelled_at: string | null; notify_email: string | null }>();
  if (!site || site.status !== "active" || site.cancelled_at) {
    return { status: 404, body: { ok: false, error: "문의를 받을 수 없는 사이트입니다" } };
  }

  const turnstile = await verifyTurnstile(env.TURNSTILE_SECRET, input.turnstileToken, request.ip);
  if (!turnstile.ok) {
    return { status: 403, body: { ok: false, error: "스팸 방지 확인에 실패했습니다. 다시 시도해 주세요." } };
  }

  const now = new Date();
  const day = now.toISOString().slice(0, 10);
  const clientHash = request.ip ? await sha256Hex(new TextEncoder().encode(`${env.HASH_PEPPER ?? "dsites"}:${day}:${request.ip}`), 32) : null;
  const windowStart = new Date(now.getTime() - 10 * 60_000).toISOString();
  const dayStart = `${day}T00:00:00.000Z`;
  const id = crypto.randomUUID();
  const createdAt = now.toISOString();
  const notify = site.notify_email ? "pending" : "skipped";
  // Limit checks and insert in one statement: D1 runs statements one at a time, so concurrent
  // submissions cannot all pass the counts before any of them is stored.
  const inserted = await env.DB.prepare(
    `INSERT INTO inquiries (id, site_id, name, phone, message, page, client_hash, notify_status, created_at)
     SELECT ?, ?, ?, ?, ?, ?, ?, ?, ?
     WHERE (? IS NULL OR (SELECT COUNT(*) FROM inquiries WHERE client_hash = ? AND created_at >= ?) < ?)
       AND (SELECT COUNT(*) FROM inquiries WHERE site_id = ? AND created_at >= ?) < ?`,
  )
    .bind(
      id, site.id, input.name, input.phone, input.message, input.page ?? null, clientHash, notify, createdAt,
      clientHash, clientHash, windowStart, LIMITS.perClient,
      site.id, dayStart, LIMITS.perSiteDay,
    )
    .run();
  if (inserted.meta.changes !== 1) {
    const siteFull =
      ((await env.DB.prepare("SELECT COUNT(*) AS n FROM inquiries WHERE site_id = ? AND created_at >= ?")
        .bind(site.id, dayStart)
        .first<{ n: number }>())?.n ?? 0) >= LIMITS.perSiteDay;
    return {
      status: 429,
      body: {
        ok: false,
        error: siteFull ? "오늘은 더 이상 문의를 받을 수 없습니다. 전화로 연락해 주세요." : "잠시 뒤 다시 시도해 주세요",
      },
    };
  }
  await bumpMetric(env.DB, site.id, "inquiry", now);

  if (site.notify_email) {
    waitUntil(notifyOwner(env, site.id, site.notify_email, { id, ...input, createdAt, hostname: request.hostname }));
  }
  return { status: 201, body: { ok: true, id } };
}

async function notifyOwner(
  env: Env,
  siteId: string,
  to: string,
  inquiry: { id: string; name: string; phone: string; message: string; page?: string; createdAt: string; hostname: string },
) {
  const name = await siteName(env, siteId);
  const phone = displayPhone(inquiry.phone);
  const lines = [
    `${name} 홈페이지로 새 문의가 들어왔습니다.`,
    "",
    `이름: ${inquiry.name}`,
    `연락처: ${phone}`,
    `접수: ${kst(inquiry.createdAt)} (한국 시간)`,
    "",
    inquiry.message,
    "",
    `보낸 곳: https://${inquiry.hostname}${inquiry.page ?? "/"}`,
  ];
  try {
    const result = await sendMail(env, {
      to,
      subject: `[${name}] 홈페이지 문의 - ${inquiry.name}`,
      text: lines.join("\n"),
      html: `<p>${escape(lines[0]!)}</p><table cellpadding="4"><tr><th align="left">이름</th><td>${escape(inquiry.name)}</td></tr><tr><th align="left">연락처</th><td><a href="tel:${inquiry.phone}">${escape(phone)}</a></td></tr><tr><th align="left">접수</th><td>${escape(kst(inquiry.createdAt))} (한국 시간)</td></tr></table><p style="white-space:pre-line">${escape(inquiry.message)}</p><p style="color:#666">보낸 곳: ${escape(`https://${inquiry.hostname}${inquiry.page ?? "/"}`)}</p>`,
    });
    await env.DB.prepare("UPDATE inquiries SET notify_status = ? WHERE id = ?")
      .bind(result.skipped ? "skipped" : "sent", inquiry.id)
      .run();
  } catch (error) {
    console.error("[inquiry] notify failed", inquiry.id, error);
    await env.DB.prepare("UPDATE inquiries SET notify_status = 'failed', notify_error = ? WHERE id = ?")
      .bind(String(error).slice(0, 500), inquiry.id)
      .run();
  }
}

export interface InquiryPage {

/** Newest first, keyset-paginated on (created_at, id) so pages never skip or repeat rows. */
export async function listInquiries(
  env: Env,
  siteId: string,
  { from, to, before, limit = 200 }: { from?: string; to?: string; before?: string; limit?: number },
): Promise<InquiryPage> {
  const size = Math.min(Math.max(Number.isFinite(limit) ? limit : 200, 1), 1000);
  const [beforeAt, beforeId] = before ? before.split("|") : [null, null];
  const { results } = await env.DB.prepare(
    `SELECT id, name, phone, message, page, notify_status, created_at FROM inquiries
     WHERE site_id = ? AND created_at >= ? AND created_at < ?
       AND (? IS NULL OR created_at < ? OR (created_at = ? AND id < ?))
     ORDER BY created_at DESC, id DESC LIMIT ?`,
  )
    .bind(siteId, from ?? "0000", to ?? "9999", beforeAt, beforeAt, beforeAt, beforeId, size + 1)
    .all<InquiryRow>();
  const page = results.slice(0, size);
  const last = page.at(-1);
  return { inquiries: page, next: results.length > size && last ? `${last.created_at}|${last.id}` : null };
}

/** Every matching inquiry, page by page (CSV export never truncates). */
export async function allInquiries(env: Env, siteId: string, range: { from?: string; to?: string }) {
  const rows: InquiryRow[] = [];
  let before: string | undefined;
  for (;;) {
    const page = await listInquiries(env, siteId, { ...range, before, limit: 1000 });
    rows.push(...page.inquiries);
    if (!page.next) return rows;
    before = page.next;
  }
}

/** Excel-friendly CSV (UTF-8 BOM, CRLF). */
export function inquiriesCsv(rows: InquiryRow[]) {
  const cell = (value: string | null) => {
    const text = value ?? "";
    // Neutralize spreadsheet formulas from visitor input.
    const safe = /^[=+\-@\t\r]/.test(text) ? `'${text}` : text;
    return `"${safe.replace(/"/g, '""')}"`;
  };
  const header = ["접수(한국 시간)", "이름", "연락처", "문의 내용", "페이지", "알림"].map(cell).join(",");
  const lines = rows.map((row) =>
    [kst(row.created_at), row.name, displayPhone(row.phone), row.message, row.page, row.notify_status].map(cell).join(","),
  );
  return `﻿${[header, ...lines].join("\r\n")}\r\n`;
}

export function requireEmail(value: unknown): string | null {
  if (value === null || value === "") return null;
  if (typeof value !== "string" || !/^[^@\s]+@[^@\s]+\.[^@\s]+$/.test(value) || value.length > 200) {
    throw new HttpError(422, "알림 이메일 형식이 아닙니다");
  }
  return value.trim();
}

/** Records one beacon. Returns what happened, for logs and tests; the router always answers 204. */
export async function recordTrack(db: D1Database, request: TrackRequest): Promise<"counted" | "ignored"> {
  const event = (request.body as { event?: unknown } | null)?.event;
  if (typeof event !== "string" || !CLIENT_EVENTS.has(event as MetricEvent)) return "ignored";
  if (!request.userAgent || BOT_UA.test(request.userAgent)) return "ignored";
  const site = await db.prepare("SELECT status, cancelled_at FROM sites WHERE id = ?")
    .bind(request.siteId)
    .first<{ status: string; cancelled_at: string | null }>();
  if (!site || site.status !== "active" || site.cancelled_at) return "ignored";
  await bumpMetric(db, request.siteId, event as MetricEvent);
  return "counted";
}

/** Totals and daily rows for a KST date range (inclusive), for reports and the console. */
export async function metricsReport(db: D1Database, siteId: string, from: string, to: string) {
  const { results } = await db
    .prepare("SELECT date, event, count FROM metrics_daily WHERE site_id = ? AND date >= ? AND date <= ? ORDER BY date, event")
    .bind(siteId, from, to)
    .all<{ date: string; event: MetricEvent; count: number }>();
  const totals = Object.fromEntries(METRIC_EVENTS.map((event) => [event, 0])) as Record<MetricEvent, number>;
  for (const row of results) totals[row.event] += row.count;
  return { from, to, totals, daily: results };
}

/**

 * large phone originals never reach the Worker's 128 MB isolate.

  const bitmap = await createImageBitmap(file, { imageOrientation: "from-image" });
  const scale = Math.min(1, MAX_EDGE / Math.max(bitmap.width, bitmap.height));
  const width = Math.round(bitmap.width * scale);
  const height = Math.round(bitmap.height * scale);
  const canvas = document.createElement("canvas");
  canvas.width = width;
  canvas.height = height;
  const context = canvas.getContext("2d");
  if (!context) throw new Error("이미지를 처리하지 못했습니다");
  context.fillStyle = "#fff"; // transparent PNGs become white, as the api does
  context.fillRect(0, 0, width, height);
  context.drawImage(bitmap, 0, 0, width, height);
  bitmap.close();
  return new Promise((resolve, reject) =>
    canvas.toBlob((blob) => (blob ? resolve(blob) : reject(new Error("이미지를 처리하지 못했습니다"))), "image/jpeg", 0.9),
  );
}

/** `srcset` for a source with variants; the original is the largest candidate when its width is known. */
export function srcSetFor(src: string, width?: number): string | undefined {
  if (!hasVariants(src)) return undefined;
  const widths = VARIANT_WIDTHS.filter((w) => !width || w < width);
  if (!widths.length) return undefined;

  // Preview: anyone with the token can view a version. Never indexed. /preview/<token>[/privacy]
  if (method === "GET" && parts[0] === "preview" && (parts.length === 2 || parts.length === 3)) {
    const version = await versionByPreviewToken(env.DB, parts[1]!);
    const site = await getSite(env.DB, version.site_id);
    const { pages } = await renderSite(JSON.parse(version.config) as SiteConfig, {
      assetBase: assetBase(),
      origin: await siteOrigin(env, site),
      preview: true,
      turnstileFrame: null,
      // Site links are root-relative (`/#inquiry`, `/privacy`); keep them inside this preview.
      linkPrefix: `/preview/${parts[1]}`,
    });
    const route = parts[2] ? `/${parts[2]}` : "/";
    const page = pages.find((entry) => entry.route === route);
    if (!page) throw new HttpError(404, "없는 페이지입니다");
    return new Response(page.html, {
      headers: {
        "content-type": "text/html; charset=utf-8",
        "x-robots-tag": "noindex, nofollow",
        "cache-control": "no-store",
      },
    });
  }

  requireAdmin(request, env.ADMIN_TOKEN);

  // MCP tools for AI agents (Streamable HTTP, stateless). Same admin token.
  if (url.pathname === "/mcp") return handleMcp(request, env);

  // PUT /admin/shared/<version>/<path>: upload one shared asset file.
  if (method === "PUT" && parts[0] === "admin" && parts[1] === "shared" && parts.length > 3) {
    const key = r2SharedKey(parts.slice(2).join("/"));
    await env.SITES.put(key, request.body, {
      httpMetadata: { contentType: request.headers.get("content-type") ?? "application/octet-stream" },
    });
    return json({ key }, 201);
  }

  // POST /validate {config}: errors without saving (console editor, scripts).
  if (method === "POST" && url.pathname === "/validate") {
    const body = await readJson<{ config?: unknown }>(request);
    const result = parseSiteConfig(body.config);
    return json(result.ok ? { valid: true, errors: [], config: result.config } : { valid: false, errors: result.errors });
  }

  // GET /domains/quota: custom hostnames on the zone vs. the 100 included.
  if (method === "GET" && url.pathname === "/domains/quota") return json(await domainQuota(env));

  if (parts[0] !== "sites") throw new HttpError(404, "없는 경로입니다");

# Workers Configuration and Observability

Use the project's Wrangler configuration and installed `node_modules/wrangler/config-schema.json` to check fields and binding declarations. Consult current product docs when a field or compatibility requirement needs verification. Doc paths below are relative to `https://developers.cloudflare.com`.

- [Binding consistency](#binding-code-consistency): configuration and code agree
- [Observability](#observability): enable logs and traces, configure sampling, and emit structured logs

## Configuration

### Keep compatibility_date current

Set `compatibility_date` to today on new projects. Encourage periodic updates on existing projects to adopt new runtime behavior and fixes. Review the intervening compatibility changes and run relevant tests when advancing the date.

**Check**: `compatibility_date` exists and supports the affected feature with the configured flags. Recommend updates as maintenance; flag a compatibility defect when the configured date or flags do not support the required behavior.

```jsonc
// wrangler.jsonc
{
  "compatibility_date": "$today",  // Replace with today's date (YYYY-MM-DD)
  "compatibility_flags": ["nodejs_compat"]
}
```

**Retrieve**: current compatibility dates at `/workers/configuration/compatibility-dates/`.

### Enable nodejs_compat

The `nodejs_compat` flag enables Node.js built-in modules (`node:crypto`, `node:buffer`, `node:stream`). Many libraries require it. Missing this flag causes cryptic import errors at runtime.

**Check**: `compatibility_flags` includes `"nodejs_compat"`.

```jsonc
{
  "compatibility_flags": ["nodejs_compat"]
}
```

### Generate binding types with wrangler types

Never hand-write the `Env` interface. Run `wrangler types` to generate it from the wrangler config. Re-run after adding or renaming any binding.

**Check**: no manually defined `Env` or `interface Env` that duplicates wrangler config bindings. Look for `satisfies ExportedHandler<Env>` pattern on the default export.

```ts
// Generated by wrangler types — always matches actual config
export default {
  async fetch(request: Request, env: Env): Promise<Response> {
    const value = await env.MY_KV.get("key");
    return new Response(value);
  },
} satisfies ExportedHandler<Env>;
```

Anti-pattern:
```ts
// Hand-written Env that drifts from actual bindings
interface Env {
  MY_KV: KVNamespace;  // What if the binding name changed?
}
```

### Store secrets with wrangler secret

Secrets must never appear in wrangler config or source code. Use `wrangler secret put` and access via `env` at runtime. Non-secret config goes in `vars`.
