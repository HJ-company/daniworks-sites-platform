# 4-B 프로덕트 오너 화면 테스트 (1회차)

코드를 모르는 프로덕트 오너 역할의 새 에이전트가 화면만으로 결제 업무 하루치를 수행. 데이터: `scripts/seed-smoke.mjs`.

| 과제 | 결과 | 점수 |
| --- | --- | --- |
| 1. 오늘 확인할 결제 파악 | 배지·확인 필요 탭으로 바로 파악, 급한 순서 정리 | 4 |
| 2. 중단 사이트 입금 처리 | 금액·기간 기본값, 처리 즉시 재공개 | 4 |
| 3. 연 구독 전환·입금·게시 | 360,000원 자동, 1년 기간, 공개 | 4 |
| 4. 연체 사장님께 공개 유지 기한 안내 | 문구 "○일 다음 날"이 모호 | 3 |
| 5. 미입금 게시 시도, 새 고객 등록·연결 | 막힌 이유는 이해, 고객은 메뉴를 오가야 함 | 3 |
| 6. 세금계산서 기록, 고객 사이트 상태 정리 | 계산서는 결제 내역에서만, 같은 상호 구분 어려움, 운영자 정지 미표시 | 3 |
| 7. 이번 달 입금 합계 | 기간 직접 지정, 건수 불일치처럼 보임 | 3 |

## 발견한 문제와 처리(커밋 "fix(console): billing findings")

| 심각도 | 문제 | 처리 |
| --- | --- | --- |
| 막힘 | 결제 내역의 일부 링크가 빈 화면(완전 삭제된 사이트) | 삭제된 사이트는 링크 없이 "(삭제됨)", 사이트·고객 화면 로딩 표시 |
| 불편 | 결제 내역에 고객 열·검색 없음, 같은 상호 구분 어려움 | 고객 열, 상호·고객·입금자 검색 |
| 불편 | 고객 상세에 운영자 정지가 안 보임 | 사이트별 공개 상태(미공개·운영·공개 중단과 사유) |
| 불편 | 고객 선택칸에서 새 고객 추가 불가, 사장님 이름·전화로 못 찾음 | 이름·전화·사업자번호 검색, "새 고객 추가" 항목 → 이름 채운 창 → 만들고 바로 연결 |
| 불편 | 고객 상세의 계산서 칸에서 바로 기록 불가 | "미발행 · 기록" 버튼으로 발행일 입력 |
| 불편 | "2026-11-29 다음 날" 모호 | "11월 29일(일)까지 공개, 11월 30일(월)부터 공개 중단" |
| 불편 | 중단·연체 사이트의 기본 기간 기준이 다름 | 기준을 입금 창에 표시(유예 중 이어서, 중단 뒤 입금일부터·중단 기간 미청구, 필요하면 시작일 조정) |
| 불편 | "이번 달" 바로 선택 없음 | 이번 달·지난달·최근 3개월 버튼 |
| 사소 | 상황 문장 잘림 | 줄바꿈 |
| 사소 | 건수 32/36 불일치처럼 보임, 버튼 어긋남, 수단 칸 빈칸 | "입금 32건 (취소 4건 제외, 목록에는 표시)", 정렬, "전체" 표시 |
| 사소 | 공급가의 부가세 여부 불명 | "부가세 별도" 표기 |
| 사소 | 김철수 중복 등록 | 같은 연락처·사업자번호면 경고 |
| 사소 | 시연 사이트의 탭 제목이 다른 상호 | 시연 데이터가 제목도 상호에 맞춤(제품 문제 아님) |
| - | 1년치 받은 뒤에도 "입금 확인" 버튼 | 유지(선납 추가 입금도 받을 수 있어야 함). 창에 기간이 보이므로 중복 확인 가능 |

# 2회차 (수정 뒤 재확인)

| 과제 | 점수(1회차 → 2회차) | 비고 |
| --- | --- | --- |
| 오늘 할 일 정리 | 4 → 5 | 상황 문장이 다 읽힘 |
| 연체 사장님 답변 | 3 → 5 | 날짜 계산 불필요 |
| 중단 사이트 입금 | 4 → 4 | 기준 안내는 이해, 앞당길 날짜 미표시 |
| 고객 화면 공개 상태·계산서 | 3 → 4 | 바로 기록, "오늘" 버튼 없음 |
| 새 고객 바로 등록·연결 | 3 → 3 | 사장님 이름이 업체명 칸에 들어감 |
| 이번 달 합계·고객 결제 찾기 | 3 → 4 | 검색 결과 합계 없음 |

남은 문제와 처리(커밋 "fix: draft link and billing findings")

| 심각도 | 문제 | 처리 |
| --- | --- | --- |
| 불편 | 새 고객 추가 시 입력한 이름이 업체명 칸에 | 업체명은 사이트 상호, 입력한 이름은 담당자 |
| 불편 | 검색 결과의 건수·합계 없음 | "검색 결과 입금 N건 · 합계"(목록이 잘렸으면 그렇게 표시) |
| 사소 | 결제 내역 기간이 화면에 다시 오면 초기화 | 기간·수단·검색어를 주소에 저장 |
| 사소 | 앞당길 시작일 미표시 | 입금 창에 날짜 표시 |
| 사소 | 계산서 발행일 "오늘" 버튼 | 추가 |
| 사소 | 확인 필요 표 세로 정렬, 흔한 상호 구분 | 가운데 정렬, 상호 아래 영문 주소 |
| 불편 | 김철수 중복 기록 | 1회차 수정(중복 경고) 이전에 만든 시연 데이터. 기존 중복 병합 기능은 두지 않음 |
