# 4-A 프로덕트 오너 화면 테스트 (1회차)

코드를 모르는 프로덕트 오너 역할 에이전트가 Playwright로 화면만 보고 수행. 데이터: `scripts/seed-smoke.mjs`.

| 과제 | 결과 | 점수 |
| --- | --- | --- |
| 1. 방문자: 중단된 사이트 | 상호와 "준비 중" 안내만. 연체·연락처 노출 없음 | 5 |
| 2. 운영자: 도메인 연결 후 사장님 안내문 작성 | 등록 성공. 안내문 작성에 필요한 정보 부족(업체별 입력, TXT 용도, 반영 시간, 루트 도메인, 복사) | 2 |
| 3. 운영자: 입금 확인 후 다시 공개 | 성공, 방문자 화면 정상 | 4 |
| 4. 운영자: 해지 시 자료 처리 안내 | 목록에 상호가 없어 찾기 어려움, 해지 창에 기술 용어(410)와 만료 후 처리 누락 | 2 |

## 발견한 문제와 처리

| 심각도 | 문제 | 처리 |
| --- | --- | --- |
| 불편 | 사이트 목록·상세에 상호가 없음 | 4-A에서 수정 |
| 불편 | 도메인 안내: 업체별 입력, TXT 용도, 반영 시간, 루트 도메인, 복사 버튼·안내문 없음 | 4-A에서 수정 |
| 불편 | 도메인 상태 확인 오류가 영어 원문 | 4-A에서 수정 |
| 불편 | 정지 사유·날짜 없음, 정지인데 "v1 공개 중" | 4-B(정지 사유, 구독 상태)에서 수정 |
| 불편 | 한 번도 공개 안 한 사이트가 "운영" + "공개 정지" 버튼 | 4-A에서 수정 |
| 불편 | 해지 창의 "(410)", 만료일·이후 처리 없음 | 4-A에서 수정 |
