# AI 에이전트 시안 작성 실측 (구축 시간 1차 측정)

- 방법: 별도 Claude Code 세션(`claude -p`, headless)을 로컬 Docker MCP(`/mcp`)에만 연결(`--strict-mcp-config`, 허용 도구 `mcp__dsites__*`). 입력은 제페스 풋볼 아카데미 네이버 블로그 RSS 최근 10개 글 요약뿐이다. 연락처는 가짜 값을 쓰고, 게시는 금지했다.
- 결과물은 로컬 Docker에만 있다(실제 업체 사진 포함, 저장소에 넣지 않음).

## 이번 측정으로 바꾼 것

- `template_get` 예시를 실제 업체 설정에서 자리표시자 뼈대로 교체했다. 다른 고객의 문구가 새 고객 사이트로 옮겨질 위험을 없앤다.
- `asset_upload(url)`이 네이버 RSS 썸네일(`blogthumb…?type=s3`, 365px)을 `postfiles…?type=w966`(약 900px)로 바꿔 받는다.

## 에이전트가 운영자 확인으로 넘긴 항목 (2회차)

실제 연락처·대표자·주소·지도·카카오, 요일별 수업 시간과 레벨, 수강료, 후기 원문, 원본 사진과 인물 게시 동의, 선수 실명 게재 여부. 자료에 없는 내용은 지어내지 않았다.

## 해석

- 자료 수집이 끝난 상태에서 AI 초안은 약 3분, 약 $1이다. PRD의 "구축 3시간" 중 남는 시간은 운영자 확인 항목(연락처, 시간표, 가격, 사진)을 고객에게 받는 일이다.
- 블로그만으로는 후기·가격·시간표가 부족하다. 시안 전 고객 확인 질문지(위 항목)를 표준화하면 왕복을 줄일 수 있다.
