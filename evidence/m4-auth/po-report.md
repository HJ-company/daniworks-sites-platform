# 4-D 프로덕트 오너 화면 테스트 (1회차)

| 과제 | 결과 | 점수 |
| --- | --- | --- |
| 1. 김운영 로그인, 누구로 들어왔는지 | 계정 버튼 하나, 이름 표시(눈에 덜 띔) | 4 |
| 2. 시안 링크 바꾸고 기록 확인 | 기록은 보이나 새로 만든 것과 바꾼 것이 같은 이름 | 3 |
| 3. 이운영으로 입금, 운영자 구분 | 작업 기록은 구분, 결제 내역에 확인자 없음 | 3 |
| 4. 권한 없는 계정 | 막힘·다른 계정 링크 정상, 문구가 어색 | 4 |
| 5. 주소로 바로 들어가기(로그인 전후) | 로그인 뒤 원래 화면으로 복귀 | 5 |

발견한 문제와 처리(커밋 "fix: who-did-what findings")

| 심각도 | 문제 | 처리 |
| --- | --- | --- |
| 불편 | 결제 내역·수정 창에 입금 확인자 없음 | 결제 내역 "확인" 열, 수정 창에 "○○이(가) 언제 확인" |
| 불편 | 시안 링크 새로 만들기와 바꾸기가 같은 기록 | "시안 링크 새로 바꿈(예전 링크 막힘)"으로 구분 |
| 불편 | 버전 표 "작성"이 "운영자"뿐 | 버전에 작성자 저장(마이그레이션 0011), "AI · 김운영"처럼 표시 |
| 사소 | 작업 기록이 페이지 맨 끝 | 사이트의 "작업 기록" 탭(최근 50건) |
| 사소 | 로그인 이름이 메뉴와 섞임 | 사람 아이콘이 있는 칩 |
| 사소 | 권한 없음 문구가 어색 | "○○ 계정에는 콘솔을 쓸 권한이 없습니다. 관리자에게 운영자 권한을 요청하세요" |
