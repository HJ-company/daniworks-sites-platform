# 4-D Authentik codex review

명령: `codex review --uncommitted`. 지적이 없어질 때까지 반복(8회).

| 회차 | 등급 | 지적 | 처리 |
| --- | --- | --- | --- |
| 1 | P1 | 만료 직전 동시 요청들이 같은 갱신 토큰을 써서 진 쪽이 로그인으로 튕김 | 갱신에 진 요청은 아직 유효한 토큰을 그대로 사용, SPA는 401이면 다시 시도 |
| 1 | P2 | MCP 도구가 거부돼도 HTTP 200이라 작업 기록에 성공으로 남음 | 도구 결과로 판정 |
| 2 | P2 | 로그인 후 돌아갈 주소에 탭 문자를 넣으면 외부로 이동 | 콘솔 출처 기준으로 해석해 같은 출처의 경로만 |
| 2 | P2 | 입력 검증 실패·없는 도구 호출이 성공으로 기록 | JSON-RPC 응답을 id로 맞춰 판정(결과 없음·error·isError는 거부) |
| 3 | P2 | `https://콘솔//evil.example`이 `//evil.example`로 돌아감 | 경로가 `//`로 시작하면 거부 |
| 3 | P2 | 사이트 생성 기록이 그 사이트 이력에 안 보임 | 생성 응답의 사이트 id로 기록(HTTP·MCP) |
| 4 | P2 | 토큰이 이미 만료된 뒤 동시 요청 경쟁 | 빌드 자산은 세션 없이 제공, SPA 재시도 2회(300ms, 1s), 만료 후 복귀 검증 추가 |
| 5 | P2 | 시안 링크 변경 뒤 작업 기록 카드가 갱신되지 않음 | 작업 기록 쿼리도 무효화 |
| 6 | P2 | 큰 토큰이면 세션 쿠키가 4KB를 넘음 | 세션을 3.5KB씩 최대 5개 쿠키로 나눔(그룹 200개 사용자로 검증) |
| 7 | P2 | 갱신 요청이 통신 오류로 던지면 아직 유효한 토큰으로도 실패 | 통신 오류도 현재 토큰으로 계속 |
| 7 | P2 | 결제 수정·취소가 사이트 이력에 안 보임 | 결제의 사이트로 기록 |
| 8 | - | 지적 없음 | - |
