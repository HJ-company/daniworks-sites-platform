# 3-3 전체 재게시 codex review

명령: `codex review --uncommitted`, 5회. 마지막 회차는 지적 없음.

| 회차 | 등급 | 지적 | 처리 |
| --- | --- | --- | --- |
| 1 | P1 | 스테이지 화면용 브라우저가 모든 요청(외부 블로그 이미지 포함)에 관리자 토큰을 보냄 | `/staged/` HTML 요청에만 라우트 단위로 토큰 추가, 토큰 유출 감시를 리포트에 포함 |
| 1 | P2 | 홈만 비교하고 개인정보처리방침 변경은 그대로 적용 | 렌더된 모든 경로 × 모바일·데스크톱 비교 |
| 2 | P2 | 적용 직전 도메인 변경이 끼면 옛 origin 렌더로 덮음 | 스테이지 당시 공개 render_id에 묶어(base_render_id) 바뀌었으면 거부 |
| 2 | P2 | 이전 배포에서 만든 스테이지를 새 배포 뒤에 적용 가능 | 스테이지의 렌더 버전이 현재와 다르면 거부 |
| 3 | P2 | 크기가 바뀐 경우 diff 이미지가 없음 | 같은 캔버스로 패딩해 diff 이미지 생성, 크기 변경은 항상 보류 |
| 3 | P2 | 렌더 교체와 재조정 표시가 따로 커밋 | 한 트랜잭션(batch), 교체가 적용됐을 때만 표시·정리 |
| 4 | P2 | `ASSET_VERSION`은 서버 렌더러만 바뀐 배포를 못 잡음 | `RENDER_VERSION` = 자산 해시 + 렌더러 소스·빌더 패키지 버전 해시. 오래됨 판정·스테이지 거부 기준 |
| 5 | - | 지적 없음 | - |
